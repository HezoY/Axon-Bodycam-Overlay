# Axon-Bodycam-Overlay
Simple program which add Axon Bodycam Overlay at screen. (At this time only FiveM LSPD:FR)

IMPORTANT!
- !!!Windows Defender can detect this program as a virus, but it is not a virus. You can check the source code and compile it yourself to be sure.!!!
- The program requires 28–35 MB of RAM, depending on its options and features. I want to minimize the program's resource usage, so I am doing everything I can to keep memory consumption as low as possible.

Program is written in Python and uses PyQt5 library for GUI. It is open source and you can find the source code on GitHub.

Logo clip into text or something other? No problem, you can move this overlay anywhere on the screen and it will stay on top of all other windows. You can also resize it to fit your needs.

Keybinds:
F10 - Show/Hide Overlay

Program save last position and size of overlay (If you dont delete settings.json), so you don't have to set it up every time you start the program.
